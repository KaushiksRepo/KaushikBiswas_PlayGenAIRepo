# OrangeHRM - Application Overview

## 1. Project Overview

OrangeHRM is an open-source Human Resource Management (HRM) web application that helps organizations manage employee information, recruitment, leave management, performance, administration, and other HR-related activities.

This project serves as a demonstration application for validating the capabilities of the AI Playwright Platform. It will be used to design, execute, and showcase enterprise-grade automated testing using Playwright, TypeScript, Cucumber BDD, and AI-driven workflows.

---

# 2. Project Objectives

The objective of this project is to:

* Demonstrate an enterprise-grade Playwright automation framework.
* Showcase AI-assisted test planning and test generation.
* Validate end-to-end business workflows.
* Demonstrate data-driven and reusable automation architecture.
* Serve as a reference project for future AI automation capabilities.
